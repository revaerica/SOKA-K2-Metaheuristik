01 · Konsep dasar

Apa itu algoritma metaheuristik?

Metaheuristik adalah strategi pencarian tingkat tinggi yang tidak bergantung pada satu jenis masalah. Ia memakai aturan acak yang terinspirasi alam untuk mencari solusi yang cukup baik dalam waktu wajar — tanpa jaminan optimal.

  • 1Tanpa gradien — hanya butuh nilai fungsi (fitness), cocok untuk masalah tak mulus / kombinatorial.
  • 2Menghindari local optima — unsur acak + banyak agen membuat pencarian tidak mudah terjebak.
  • 3Fleksibel — satu algoritma dipakai ulang untuk banyak masalah; cukup ganti fungsi fitness.
  • 4Cocok untuk masalah NP-hard seperti task scheduling, saat mencoba semua kemungkinan mustahil.
Mirjalili 2015Saremi dkk. 2017Abualigah & Diabat 2021

03 · Dua contoh algoritma (berdasarkan paper)

Singa-semut dan belalang

🐜

Ant Lion Optimizer (ALO)

Mirjalili (2015), Advances in Engineering Software

Terinspirasi cara singa-semut (antlion) berburu: menggali perangkap berbentuk corong di pasir, semut berjalan acak lalu terjebak; singa-semut memangsa dan membangun ulang perangkap.

  • • Dua populasi: semut (pencari) & antlion (solusi bagus)
  • • Hanya sedikit parameter — mudah dipakai
  • • Versi cloud: MALO = ALO + elite-based Differential Evolution
DOI · algoritma asliDOI · Abualigah & Diabat 2021
🦗

Grasshopper Optimization (GOA)

Saremi, Mirjalili & Lewis (2017), Advances in Engineering Software

Terinspirasi perilaku kawanan belalang: tarik–menarik & tolak–menolak antar belalang yang saling berinteraksi sambil bergerak menuju sumber makanan (target).

  • • Satu populasi; tiap agen dipengaruhi semua agen lain
  • • Fungsi sosial s(r): tolak / nyaman / tarik
  • • Koefisien c menurun → eksplorasi ke eksploitasi
DOI · algoritma asliDOI · Zhao dkk. 2019

ALO · Ant Lion Optimizer

Enam mekanisme perburuan singa-semut

  • 1Semut berjalan acak mencari makanan — ini langkah eksplorasi.
  • 2Membangun perangkap: antlion dipilih lewat roulette wheel — yang fitness-nya lebih bagus lebih mungkin terpilih.
  • 3Semut terperangkap: jalan acak dibatasi di sekitar antlion terpilih (dan elite).
  • 4Perangkap menyempit: radius jalan acak mengecil tiap iterasi (rasio I membesar) → eksploitasi.
  • 5Menangkap mangsa & membangun ulang: jika semut lebih baik dari antlion, antlion pindah ke posisi semut.
  • 6Elitisme: antlion terbaik (elite) memengaruhi semua semut, tidak pernah hilang.

RUMUS INTI

$$X(t)=[0,\ \mathrm{cumsum}(2r(t_1)-1),\ \dots,\ \mathrm{cumsum}(2r(t_T)-1)]$$

Jalan acak: tiap langkah +1 atau −1 (r = 0 atau 1 acak).

$$c^t=\dfrac{c^t}{I},\qquad d^t=\dfrac{d^t}{I}\quad(\text{perangkap menyempit})$$
$$X_i^t=\dfrac{(X_i^t-a_i)(d_i^t-c_i^t)}{b_i-a_i}+c_i^t\quad(\text{normalisasi ke batas})$$
$$\mathrm{Ant}_i^t=\dfrac{R_A^t+R_E^t}{2}$$

RA: jalan acak sekitar antlion terpilih (roulette), RE: sekitar elite.

$$f(\mathrm{Ant}_i^t) < f(\mathrm{Antlion}_j^t) \;\Longrightarrow\; \mathrm{Antlion}_j^{t+1}=\mathrm{Ant}_i^t$$

GOA · Grasshopper Optimization Algorithm

Tarik, tolak, dan zona nyaman

Belalang muda (nimfa) bergerak pelan & kecil → eksploitasi. Belalang dewasa melompat jauh → eksplorasi. Posisi belalang i ditentukan oleh interaksi sosial dengan belalang lain plus tarikan ke target (solusi terbaik).

$$X_i=c\left(\sum_{\substack{j=1\\ j\ne i}}^{N} c\,\dfrac{ub-lb}{2}\,s\!\left(|x_j-x_i|\right)\dfrac{x_j-x_i}{d_{ij}}\right)+\hat T_d$$
$$s(r)=f\,e^{-r/l}-e^{-r},\qquad c=c_{max}-t\,\dfrac{c_{max}-c_{min}}{T}$$
  • ss(r) < 0 → tolak (terlalu dekat) · s(r) = 0 → zona nyaman · s(r) > 0 → tarik.
  • cKoefisien c menurun tiap iterasi: mempersempit zona tarik/tolak dan menggeser fokus dari eksplorasi ke eksploitasi.
  • TGravitasi & angin diabaikan; target T̂ = solusi terbaik sejauh ini.
Fungsi sosial s(r) — ubah parameternya!

Standar paper: f = 0,5 dan l = 1,5.

05 · Dari agen ke jadwal

Satu agen = satu jadwal lengkap

  • 1Posisi agen adalah vektor x dengan n dimensi (satu dimensi per tugas), nilai di [0, m).
  • 2Decode: VM tugas j = ⌊xj⌋. Algoritma tetap bekerja di ruang kontinu.
  • 3Fitness = makespan jadwal hasil decode (lebih kecil lebih baik).
  • 4ALO / GOA memperbarui x → decode → hitung fitness → ulangi.

Coba sendiri: klik chip tugas untuk memindahkannya ke VM berikutnya, atau biarkan algoritma yang mencari.

05 · Algoritma untuk cloud task scheduling di paper

Apa yang dilakukan paper-paper tersebut?

Abualigah & Diabat (2021) · Cluster Computing

Hybrid ALO untuk multi-objective task scheduling

  • • Algoritma usulan: MALO — antlion optimizer yang digabung elite-based Differential Evolution sebagai local search.
  • • Alasan: ALO murni kurang kuat di eksploitasi & bisa terjebak local optima; DE memperbaiki solusi di sekitar elite.
  • • Tujuan: minimalkan makespan & maksimalkan resource utilization saat menjadwalkan tugas ke VM.
  • • Uji: simulator CloudSim, dataset sintetis dan real trace, dibanding optimizer lain.
  • • Klaim paper: unggul dari pembanding, konvergensi lebih cepat pada ruang pencarian besar, signifikan secara uji-t.
doi.org/10.1007/s10586-020-03075-5
Zhao, Ni, Feng, Song & Zhu (2019) · IJICIC 15(5)

GOA untuk penjadwalan tugas di cloud

  • • Memakai kerangka GOA (Saremi dkk., 2017) untuk memetakan tugas cloud ke sumber daya.
  • • Gagasan umum yang kita peragakan di simulasi: setiap belalang = satu jadwal; posisi kontinu di-decode menjadi indeks VM; fitness = makespan.
  • • Interaksi sosial antar-jadwal (tarik/tolak) menjaga keragaman solusi sambil perlahan menuju target terbaik.

05 · Penerapan di dunia nyata

Di mana lagi metaheuristik dipakai?

☁️
Cloud task scheduling

Menjadwalkan ribuan tugas ke VM agar waktu selesai (makespan) singkat dan sumber daya terpakai efisien — fokus proyek ini.

📡
IoT & edge/fog computing

Memutuskan tugas diproses di perangkat, edge, atau cloud untuk menekan latensi dan energi baterai.

🔋
Data center hemat energi

Konsolidasi VM & penempatan beban agar server menganggur bisa dimatikan tanpa melanggar SLA.

🚚
Logistik & penugasan tugas

Penugasan pekerjaan/armada pada cloud logistics — GOA pernah diterapkan pada masalah task assignment tersebut.

🛠️
Desain rekayasa

Optimasi struktur & komponen (mis. desain baling-baling kapal pada paper ALO) di mana turunan fungsi sulit dihitung.

🧠
Machine learning

Tuning hyper-parameter, feature selection, dan pelatihan jaringan saraf tanpa gradien.

Pola yang sama: definisikan representasi solusi + fungsi fitness → biarkan populasi mencari. Hanya dua bagian itu yang berganti antar masalah.

06 · Penutup

Kesimpulan & sumber paper

Poin utama
  • 1Metaheuristik = pencarian acak terarah berbasis populasi; ideal untuk masalah NP-hard.
  • 2ALO menyempitkan jalan acak semut di sekitar antlion & elite; GOA memakai gaya sosial belalang yang melemah seiring c menurun.
  • 3Pada task scheduling, agen = jadwal; decode posisi → VM; fitness = makespan (+ utilization).
  • 4Hibridisasi (mis. ALO + DE → MALO) memperkuat eksploitasi dan mempercepat konvergensi.
