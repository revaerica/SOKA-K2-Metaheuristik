## Presentasi interaktif: Metaheuristik, ALO & GOA untuk Cloud Task Scheduling

Buka `index.html` di browser (butuh internet untuk CDN Tailwind CSS, Three.js, KaTeX, dan font). Untuk hasil terbaik jalankan server lokal, mis. `python -m http.server` lalu buka `http://localhost:8000`.

**Navigasi:** `←` `→` pindah slide, `F` layar penuh, klik titik di bawah untuk lompat.

| File | Isi |
|---|---|
| `index.html` | 15 slide (Tailwind CSS) |
| `css/style.css` | Tema, animasi, komponen |
| `js/core.js` | Implementasi ALO, GOA, MALO-ringkas, model cloud scheduling, helper canvas |
| `js/viz-intro.js` | Demo metaheuristik (hill-climbing vs populasi), eksplorasi→eksploitasi |
| `js/viz-alo.js` | Visualisasi ALO di peta fitness |
| `js/viz-goa.js` | Fungsi sosial s(r) + visualisasi GOA |
| `js/viz-sched.js` | Kalkulator ruang pencarian, demo encoding, arena ALO vs GOA |
| `js/main.js` | Navigasi slide + latar 3D Three.js |
